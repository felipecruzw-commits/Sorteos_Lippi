1 Traer los comentarios

No se guarda en ningún sitio: se pierde al cerrar o recargar la página.
¿Cómo obtengo gratis el token y el User ID?
  1. Convierte tu Instagram en cuenta Profesional (Empresa o Creador) y vincúlala a una Página de Facebook.
  2. En developers.facebook.com crea una app de tipo Empresa.
  3. Abre el Explorador de la API Graph, elige tu app y genera un token de usuario con los permisos instagram_basic, instagram_manage_comments y pages_show_list.
  4. Con ese token consulta me/accounts?fields=instagram_business_account. El id dentro de instagram_business_account es tu Instagram User ID.
  5. En modo desarrollo, con tu propia cuenta como administrador, no hace falta la revisión de Meta.
Formatos: líneas usuario: comentario, CSV con cabecera (username,text,timestamp) o JSON.

2 Reglas del sorteo

Sus comentarios y menciones se excluyen.
0 = no se exige. Solo cuentan menciones únicas.
Los comentarios posteriores no cuentan.
Si lo desactivas, cada comentario válido da un boleto.
Instagram no permite leer seguidores por API. Descarga tu información: Configuración → Centro de cuentas → Tu información y permisos → Descargar tu información → Seguidores y seguidos → formato JSON. Sube followers_1.json, followers_2.json, etc.
